# کندل‌آدیت — CandleAudit

ابزار متن‌باز و مستقل برای بررسی کیفیت داده‌های کندلی و شناسایی بخشی از خطاهای متداول بک‌تست.

این پروژه **استراتژی معاملاتی نیست** و هیچ کد خصوصی، اطلاعات حساب، نتیجه پژوهش محرمانه یا منطق اجرای سفارش واقعی در آن وجود ندارد. مثال‌ها کاملاً ساختگی هستند.

## امکانات نسخه ۰٫۲

- بررسی گپ زمانی، تکرار کندل، ترتیب نادرست، مقدارهای OHLC غیرمعتبر و حجم منفی.
- بررسی این‌که زمان واقعی در دسترس بودن یک ویژگی (`available_at`) دیرتر از لحظه تصمیم (`signal_time`) نباشد.
- بررسی ورود روی ابتدای کندل بعدی و محاسبه ساده سود و زیان معاملات بسته‌شده همراه با کارمزد دوطرفه.

## نصب و اجرا

```bash
python -m pip install -e .
candleaudit candles examples/candles_bad.csv --interval 4h
candleaudit features examples/features_bad.csv
candleaudit trades examples/trades_clean.csv --candles examples/candles_clean.csv
python -m unittest discover -s tests -v
```

کد خروج: ۰ بدون خطا، ۱ وجود خطای تشخیص‌داده‌شده، ۲ مشکل فایل یا پارامتر. خروجی JSON است و با `--output report.json` ذخیره می‌شود.

**محدودیت:** عبور از آزمون به‌معنای اثبات سودآوری یا نبود کامل خطای نگاه به آینده نیست. افت سرمایه در مثال معاملات، فقط بر مبنای سود و زیان تحقق‌یافته است و افت شناور واقعی، پوزیشن‌های همزمان، فاندینگ و لیکوییدیشن محاسبه نمی‌شود.

برای جزئیات فنی [README انگلیسی](README.md)، [طراحی](docs/design.md)، [راهنمای راستی‌آزمایی](docs/VERIFICATION.md) و [مشارکت](CONTRIBUTING.md) را بخوانید.

پروژه مستقل [CandleBacktest AI](https://github.com/aliyousefiyan/candlebacktest-ai) موتور بک‌تست آزمایشی است؛ CandleAudit موتور بک‌تست نیست و اتصال فعلی آن به پروژه دیگر فقط ممیزی داده‌های کندلی را پوشش می‌دهد.

## نصب مستقیم از GitHub

```bash
python -m pip install "git+https://github.com/aliyousefiyan/candleaudit.git"
candleaudit --help
```

معامله‌هایی که خطای ساختاری دارند وارد محاسبه نمونه سود و زیان نمی‌شوند. نتایج این ابزار تأیید استقلال بک‌تست از اطلاعات آینده یا اثبات سودآوری نیست.
